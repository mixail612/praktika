# Практика

Локальное приложение для подготовки практических учебных работ с помощью
OpenAI-совместимых моделей: от файла задания до редактируемого документа Word.
Работает на вашем компьютере, интерфейс открывается в браузере.

- **Практический режим:** обязательный файл задания, необязательные лекции и
  предыдущие работы, один промпт с требованием выполнять только заданные пункты.
- **Расширенный режим:** тема, объём, структура, отдельные инструкции для разделов.
- **Редактор:** разделы, абзацы, списки, таблицы и управление разрывами страниц.
- **Агент:** правки по сообщению, файлы в чате, необязательный поиск в интернете
  и отмена последнего набора правок.
- **Модели:** один активный роутер, каталог с авторизацией, выбор модели и
  старательности для работы; последняя выбранная модель запоминается.
- **Оформление:** поля, шрифт, интервалы, титульный лист, содержание, нумерация
  и вывод; предпросмотр А4, экспорт DOCX и печать в PDF через браузер.

Основная платформа — **Windows 10/11 x64**. Docker не требуется.
Генерация использует ваш API-ключ и оплачивается по тарифам выбранного провайдера.
Без модели доступны ручное редактирование и экспорт.

## Установка на Windows

Если владелец репозитория опубликовал Windows-релиз, скачайте из раздела
**Releases** архив `Praktika-windows-x64.zip` и распакуйте его целиком.
Откройте `Praktika/Praktika.exe`. Устанавливать Python не нужно.
Один EXE отдельно от папки `_internal` работать не будет.

Небольшое окно «Практика» управляет сервером. Кнопка открывает интерфейс, закрытие
окна завершает приложение. Закрытие вкладки браузера сервер не останавливает.
Перед выходом дождитесь сохранения и завершения генерации.

Если готового релиза ещё нет, используйте запуск из исходников ниже.

## Запуск из исходников

Установите **Python 3.11 x64** с официального сайта Python и скачайте исходники.
В папке проекта откройте PowerShell:

```powershell
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe main.py
```

Или запустите `start.bat`: он откроет готовую сборку, если она есть в `dist`,
иначе создаст `.venv` и запустит исходники. Для разработки запускайте `main.py`
напрямую, чтобы случайно не открыть старую сборку.

По умолчанию интерфейс доступен на http://127.0.0.1:8765.
Сервер слушает только локальный адрес. Для запуска без окна и автооткрытия браузера:

```powershell
.venv/Scripts/python.exe main.py --no-browser
```

В этом режиме остановка — Ctrl+C в терминале. Браузер должен оставаться открытым
только для работы с интерфейсом; генерация выполняется на локальном сервере.

## Первая практическая работа

1. Откройте **Настройки**, введите адрес OpenAI-совместимого API и ключ, нажмите
   **Подключить роутер**. Адрес должен вести на базовый API, например
   `https://api.openai.com/v1` или `https://openrouter.ai/api/v1`,
   без `/chat/completions` в конце.
2. Создайте работу в практическом режиме. Загрузите **файл задания**. Если нужны,
   раскройте дополнительные материалы и добавьте лекции и предыдущие работы.
   Поддерживаются PDF, DOCX, TXT и MD, до 20 МБ на файл.
3. Проверьте промпт. В параметрах генерации выберите модель и при необходимости
   старательность. Поиск и ручной ввод ID модели находятся в дополнительных параметрах.
4. Составьте план — приложение откроет редактор. Уточните разделы и сгенерируйте
   текст всей работы или выбранного раздела. Результаты сохраняются по мере готовности.
5. Вносите правки вручную или через агента. В его строке сообщения «＋» прикрепляет
   файлы, «⋯» открывает дополнительные действия, стрелка отправляет сообщение.
   Enter отправляет, Shift+Enter переносит строку. Во время запроса доступна остановка.
6. Настройте оформление и состав документа, откройте предпросмотр и скачайте DOCX.
   Для PDF используйте печать браузера с сохранением в PDF и отключёнными колонтитулами.

Готовность и ошибки показываются уведомлениями, текущая генерация — индикатором
прогресса. Новая генерация раздела заменяет его текст. Сохраняйте важные версии
через экспорт перед значительными изменениями.

## Подключение моделей

Каталог `/models` запрашивается с введённым или сохранённым ключом. Для локального
API без ключа нужно явно включить **Сервер без авторизации**. Если каталог не
поддерживается (404/405/501), можно сохранить подключение и вручную указать ID
модели. Это не подтверждает, что генерация уже работает.

Используется **Chat Completions API**. Модель должна возвращать структурированный
ответ по инструкции; совместимость зависит от конкретной модели и роутера.
В настройках подключения доступны лимит ответа, параметр лимита токенов и температура.
Для некоторых reasoning-моделей нужен `max_completion_tokens`.

Старательность передаётся параметром `reasoning_effort`. Список моделей не всегда
сообщает поддерживаемые уровни. Если провайдер отклоняет значение, выберите
«По умолчанию модели» или поддерживаемый уровень. При обрезанном ответе увеличьте
лимит токенов или генерируйте меньшие разделы.

Лимит материалов измеряется в **символах**, а не токенах. Контекст запроса также
включает задание, структуру, промпты и текст работы. Он должен помещаться в окно
выбранной модели. Сканы PDF требуют предварительного OCR; автоматического OCR нет.
Оригинальные файлы не сохраняются — сохраняется извлечённый текст.

## Оформление и ограничения

Базовое оформление: А4, Times New Roman 14 пт, интервал 1,5, абзацный отступ
12,5 мм, поля 30/15/20/20 мм. Это настраиваемая основа для учебных работ,
**не гарантия соответствия любому ГОСТу**. Проверьте требования вашей методички.
Шрифт должен быть установлен в системе; файлы коммерческих шрифтов не поставляются.

Титульный лист, содержание, номера страниц и вывод включаются независимо.
В Word после открытия документа обновите поля: **Ctrl+A → F9** (иногда Fn+F9).
Титульный лист учитывается в нумерации, но номер на нём скрыт.
Предпросмотр браузера и Word могут по-разному переносить текст и таблицы;
окончательную вёрстку проверяйте в Word. Целевое число страниц — ориентир для модели.

Агент может искать через Bing и читать публичные текстовые страницы без отдельного
поискового ключа. Поиск зависит от доступности сервиса; сайты с авторизацией,
сложным JavaScript и сканы не поддерживаются. За одно сообщение разрешено до
8 шагов модели и 6 обращений в интернет. Каждый запрос модели может оплачиваться.
Правки проверяются и применяются вместе. Отмена последних правок доступна, пока
после агента не было ручных изменений. Проверяйте факты, расчёты и источники.

Отмена генерации отбрасывает результат текущего запроса; уже завершённые разделы
сохраняются. Сам запрос провайдера может продолжаться до тайм-аута 180 секунд.
После перезапуска незавершённые задания автоматически не возобновляются.
Совместное редактирование в нескольких вкладках не поддерживается.

## Данные и приватность

Работы, история агента, извлечённые тексты и подключения находятся в
`%LOCALAPPDATA%/Praktika`. API-ключи хранятся отдельно через системное хранилище
Windows, служба `Praktika`. Поле ключа открывается замаскированным, глазок раскрывает
его по нажатию. Пустое поле при сохранении оставляет прежний ключ.

Для резервной копии закройте приложение после завершения заданий и скопируйте
папку данных. Ключи в неё не входят: на другом компьютере введите их повторно.
При генерации контекст передаётся выбранному провайдеру, при веб-поиске запросы
отправляются поисковику. Подробности — в [SECURITY.md](SECURITY.md).

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `PRAKTIKA_DATA` | Отдельная папка данных и журнала | `%LOCALAPPDATA%/Praktika` на Windows |
| `PRAKTIKA_PORT` | Порт локального сервера | `8765` |

Пример смены порта в PowerShell:

```powershell
$env:PRAKTIKA_PORT = "8766"
.venv/Scripts/python.exe main.py
```

`.env.example` — справочник: `.env` автоматически не загружается.
Журнал находится в `app.log` внутри папки данных.

## Частые вопросы

**Модели не загружаются.** Проверьте базовый адрес API, ключ, баланс и доступность
роутера. Если `/models` отсутствует, введите ID вручную. Успешное получение каталога
не гарантирует доступ к каждой модели.

**Не удаётся сохранить ключ.** Проверьте доступ к системному хранилищу Windows.
Приложение не подменяет его хранением ключей в открытом файле.

**Порт занят.** Если уже запущена «Практика», повторный запуск откроет её интерфейс.
Если порт занимает другая программа, задайте `PRAKTIKA_PORT`.

**Файл не читается.** Проверьте формат и отсутствие пароля; для сканов выполните OCR.
Лимит извлечённого текста — 1 млн символов на файл.

**Windows предупреждает о запуске.** Самостоятельная сборка не имеет цифровой подписи.
Используйте доверенные исходники или сборку владельца репозитория.

**Нужен ли Docker?** Для локальной Windows-программы — нет. Приложение использует
окно управления и системное хранилище ключей. Причины описаны в
[архитектуре](docs/architecture.md). Linux CI проверяет серверную часть, но готовые
настольные сборки и настройка keyring для Linux/macOS пока не поддерживаются.

## Разработка и выпуск

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m ruff check .
.venv/Scripts/python.exe -m ruff format --check .
```

`build.bat` проверяет проект и собирает `release/Praktika-windows-x64.zip`.
`python scripts/package_source.py` создаёт чистый архив для первой публикации,
без личных файлов из рабочей папки.
