# Безопасность и приватность

Приложение предназначено для одного пользователя на локальном компьютере.
Сервер слушает `127.0.0.1`, проверяет Host и Origin, запрещает встраивание во фрейм.
Это не многопользовательский сервер: аккаунтов и сетевой авторизации нет.
Не публикуйте его порт через прокси, туннель или контейнер в общей сети.

API-ключи сохраняются через `keyring` в системном хранилище Windows и не входят
в файлы работ. Проекты, сообщения и извлечённые тексты хранятся на диске без
дополнительного шифрования. Резервную копию папки данных храните как личные данные.
Ключи нужно переносить отдельно, повторно подключая роутер.

При генерации материалы и текст работы отправляются выбранному API-провайдеру.
При включённом интернете агент передаёт запросы Bing и читает публичные страницы;
содержимое страниц попадает в контекст модели. Учитывайте условия этих сервисов.
Файлы и веб-страницы недоверенные; проверяйте результат агента перед экспортом.
Приложение не исполняет произвольный код модели.

При обнаружении уязвимости используйте приватное сообщение через вкладку Security
репозитория, если владелец включил Private vulnerability reporting. Иначе сначала
создайте issue без деталей эксплуатации и секретов, запросив приватный канал.
Не публикуйте API-ключи, личные работы и содержимое системного хранилища.
Поддерживается актуальный код основной ветки; фиксированного SLA нет.
