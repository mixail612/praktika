Настройки роутера

Выберите роутер для всех работ. В каждой работе выбирается только модель.

При подключении запрос /models отправляется с вашим API-ключом. Ключ сохраняется в системном хранилище Windows. Для существующего роутера пустое поле использует сохранённый ключ.
